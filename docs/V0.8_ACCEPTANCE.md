- B 課表：完整週一至週日週視圖；42 格月視圖顯示每日有效堂數，取消及已改期原紀錄不計入。
- C 時長：支援 30、45、60、90、120、180 分鐘及 15～360 分鐘自訂值；可自動計算或手動覆寫結束時間，禁止跨越午夜。
- D 課後流程：依 v0.8.1 改為到時自動完成；老師仍可事後更正結果與扣堂方式。
- E 學生科目：支援多科目、預設科目、精簡摘要及任一科目搜尋；舊 `subject` 安全遷移。
- F 改期：支援只改這堂、這堂與之後、整個系列；保留 `rescheduleHistory`，已扣堂時自動還原。
- G 導覽：五步跨頁情境導覽，具進度、上一步、略過、穩定 `data-tour-id` 與可恢復步驟。
- H 提醒：首頁最後一堂／零堂數提醒；Android 系統通知每天最多一次，未授權時不影響首頁。
- I 相容性：保留 `xiaokebiao_mvp_v1`、GitHub Pages、PWA 與永久 Android applicationId `io.github.lobster0213.xiaokebiao`。

## v0.8.1 自動完成重點

- `scheduled` 與舊 `inProgress` 課程逾時皆會自動完成。
- 正式包堂餘額大於 0 時只扣一次；餘額為 0 時完成但不扣堂，也不會在日後加堂時追扣。
- 按次計費與試教自動完成但不扣正式堂數；試教結果仍保持原值。
- App 啟動、每 45 秒、重新取得焦點、頁面恢復及 Android `onResume` 都會重跑同一個冪等檢查。
- 系統自動完成的課程顯示時間，且老師更正、改期、刪除與復原都會重新對帳並保留異動。
