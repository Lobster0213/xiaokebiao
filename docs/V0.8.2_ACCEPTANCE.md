# 小課表 v0.8.2 驗收紀錄

日期：2026-08-11  
分支：`feature/v0.8.2-series-and-record-management`  
修改前備份：`backup/v0.8.1-before-v0.8.2`（`357c4d7`）

## A～O 驗收

- A｜資料遷移：`dataVersion` 由 8 升為 9；舊資料補上 policy、history、batch 與 backup 欄位，重複 migration 不新增重複帳本交易。
- B｜系列識別：所有系列操作只選取相同 `recurrenceGroupId`。
- C｜系列刪除：支援僅此堂、此堂及之後、整個系列；顯示實際影響、完成與扣堂數。
- D｜刪除對帳：已完成課程可選還原堂數或保留帳本；所有加回走 `LessonCreditTransaction`。
- E｜Batch Undo：批次操作有獨立 `batchOperationId` 與 8 秒 `undoUntil`，只復原該批。
- F｜系列編輯：可整批修改日期／星期、時間、時長、科目、形式與地點；完成課程預設排除。
- G｜衝堂策略：先預覽，再返回修改、跳過衝突或在最多 104 週內往後補足。
- H｜暫停／跳過：可選單堂或日期區間；`skipped` 不自動完成、不扣堂、不佔用衝堂時段，可選補足。
- I｜增加堂數：支援 +1、+2、+4、+8、自訂 1～100；沿用系列設定與 `recurrenceGroupId`，可整批 Undo。
- J｜扣堂規則：老師全域設定學生請假／缺席；學生可繼承或覆蓋；單堂可臨時覆蓋。
- K｜自動完成：保留課後自動完成與一次扣堂；沒有新增待確認、開始上課或記一堂流程。
- L｜最近紀錄：課表及學生頁顯示最近 7 天自動完成課程；可改請假、取消、缺席或改期並自動 reconcile。
- M｜安全備份：顯示上次備份時間／筆數；匯入前 snapshot；驗證後才提交；失敗不覆寫；成功後可復原本次匯入。
- N｜學生統計：分開顯示剩餘可用堂數、未來已排堂數與最後日期；超排只提醒，不阻止排課。
- O｜手機課表：390×844 顯示完整七天，課程時間／姓名字級為 9／10 px；週時段可延伸 05:00～24:00，有回到現在、current-time line、完整日清單與學生／科目／狀態篩選。
